# Kiran's Game Dev Starter

Create a basic, responsive personal portfolio website blueprint for beginner Game Developer Kiran Praveen. Use the requested dark gaming-inspired design: very dark charcoal background, dark gray cards, electric purple primary accent, restrained blue/cyan secondary accent, off-white text, gray secondary text. Include sticky smooth-scroll navigation (Home, About, Projects, Skills, Contact); a sparse Home hero with name, title, short placeholder intro, Projects and Contact buttons; simple easy-to-edit About placeholder; a clean 3–6 placeholder project card grid with placeholder images, title, short placeholder description, and view button; simple skill tags such as Unity, C#, Game Development; and Contact with placeholder email/GitHub/LinkedIn. Keep it clean, modern, minimal, professional, responsive, and clearly a starter blueprint. Do not invent experience, achievements, stats, testimonials, detailed case studies, heavy motion, or extra sections.
